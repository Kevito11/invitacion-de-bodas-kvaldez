# Invitación de Bodas

Este proyecto es una aplicación interactiva diseñada para gestionar y presentar invitaciones de boda de manera moderna y digital. Permite a los invitados visualizar detalles del evento, confirmar su asistencia y acceder a información relevante de la celebración.

> [!IMPORTANT]
> **Nota de uso:** Este proyecto es de carácter **estrictamente personal** y ha sido desarrollado como parte de un **curso de formación**. No está destinado a un uso comercial masivo, ya que su propósito es exclusivamente educativo y de práctica personal.

## Características Principales

- **Interfaz Moderna y Elegante:** Diseño responsive que garantiza una excelente visualización tanto en dispositivos móviles como en computadoras de escritorio.
- **Confirmación de Asistencia (RSVP):** Los invitados pueden confirmar su presencia, indicar el número de acompañantes y dejar mensajes adicionales.
- **Gestión de Datos:** Integración con servicios en la nube para el almacenamiento y recuperación de las confirmaciones en tiempo real.
- **Experiencia de Usuario:** Micro-animaciones y efectos visuales que aportan un toque premium a la invitación.

## Tecnología Utilizada

- **Frontend:** React, TypeScript, Vite.
- **Estilos:** CSS3 personalizado con un enfoque en diseño moderno.
- **Backend/Base de Datos:** Supabase para la persistencia de datos y confirmaciones.
